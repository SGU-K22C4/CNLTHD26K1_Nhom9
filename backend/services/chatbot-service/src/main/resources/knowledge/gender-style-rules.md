# Gender Style Rules

## Rule mac dinh
- Neu user da login va co gender profile, uu tien loc theo gender do.
- Neu query lech manh so voi profile gender, hoi lai nhe:
  - "Ban dang muon xem do nu de mua cho ban than hay mua giup nguoi khac vay?"

## Nu - Di lam
- blouse + trouser thang
- ao so mi tucked in + quan tay
- dam midi don sac
- smart casual: tee chat + blazer + trouser

## Nu - Cuoi tuan
- tee + jeans + sneaker
- blouse nhe + wide leg + mule
- uu tien thoai mai va de phoi

## Nu - Du tiec
- dam wrap midi
- vay/ao kieu co diem nhan nhung khong qua busy

## Nam - Di lam
- so mi trang/xanh nhat + trouser den/xam
- polo + chino + loafer cho smart casual
- blazer navy la mon nang cap nhanh

## Nam - Cuoi tuan
- tee trang + jeans + sneaker
- so mi linen + jeans/chino
- fit dep quan trong hon viec nhieu chi tiet

## Rule hoi lai
- Nam hoi dam/vay, hoac nu hoi ao so mi nam ro rang -> hoi mua cho ban than hay mua giup.
- Neu user xac nhan mua giup nguoi khac -> tam chuyen target gender theo query hien tai.
