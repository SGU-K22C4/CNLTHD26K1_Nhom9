# Seasonal Style Rules

## Mua he
- Uu tien: linen, cotton, bamboo, jersey nhe.
- Mau: trang, be, pastel, earthy tone nhat.
- Nu: ao thun trang + quan linen, vay midi nhe.
- Nam: so mi linen + chino, tee + short kaki.

## Mua thu
- Uu tien: denim, canvas, knit mong, layer nhe.
- Mau: camel, olive, navy, rust.
- Nu: trench be + dam midi den.
- Nam: tee trang + blazer navy + chino.

## Mua dong
- Uu tien: wool blend, fleece, knit day, outerwear.
- Mau: den, navy, xam, kem, camel.
- Nu: turtleneck + trouser + wool coat.
- Nam: knit co cao + trouser + ao khoac.

## Mua xuan
- Uu tien: cotton nhe, chiffon, linen nhe, cardigan mong.
- Nu: dam wrap + ao khoac nhe.
- Nam: so mi ke nhat + chino.

## Rule su dung
- Neu user noi "nong", "mat", "thoang" -> uu tien summer materials.
- Neu user noi "giu am", "layer" -> uu tien winter/fall materials.
- Khong goi y vai day cho mua he neu user uu tien daily comfort.
