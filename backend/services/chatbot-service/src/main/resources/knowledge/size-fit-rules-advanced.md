# Size Fit Rules Advanced

## Tang 1 - Rule chung theo height weight
- Height/weight chi la estimate, khong du de chot size tuyet doi.
- Cach noi uu tien:
  - "Ban thuong nam trong khoang S-M."
  - "Neu muon form thoai mai hon thi nghieng M."

## Tang 2 - Rule theo category

### Ao so mi va blouse
- Uu tien vai va nguc.
- Neu vai rong hoac nguc tu 88cm tro len, co xu huong len 1 size.
- Zara form slim o vai nen khong nen chot size sat nguoi qua.

### Ao thun basic
- Thuong dung size.
- Neu thich relaxed fit thi len 1 size.

### Knitwear cardigan ao len
- Thuong dung size vi co do gian.
- Chi len size khi user muon layering ro rang.

### Quan tay trousers jeans straight
- Uu tien eo, hong, dui.
- Neu mong/dui day thi len 1 size an toan hon.
- Wide leg va straight leg thuong de mac hon skinny.

### Jeans skinny
- Co the len 1 den 2 size neu user mo ta bi chat o dui hong.

### Vay va dam
- Uu tien eo va hong hon can nang.
- Midi/maxi can hoi them chieu cao neu user duoi 160cm.

### Blazer trench outerwear
- Uu tien vua vai.
- Thuong len 1 size neu can layering.

## Tang 3 - Rule theo fit type

### Slim fit
- Nho user neu dang ao/quan slim se chat hon.
- Khong duoc noi chac chan size neu user chua co so do phan vai/nguc/eo/hong.

### Regular fit
- Dung size la mac dinh.
- Neu user phan van giua 2 size, hoi muc do om hay thoai mai.

### Oversized
- Dung size van co the rong san.
- Chi xuong 1 size neu user muon giu oversize vua phai.

### Wide leg
- Uu tien eo va do dai.
- Goi y sua lai gau neu user qua thap.

## Muc do chac chan
- Khong duoc dung cau "ban chac chan mac size X".
- Duoc dung:
  - "Mình nghiêng ve..."
  - "An toan hon la..."
  - "Neu thich om thi..., neu thich thoai mai thi..."

## Follow-up nen hoi
- Ao/blazer: vai, vong nguc, brand dang mac.
- Quan/jeans: eo, hong, dui, thich om hay rong.
- Vay/dam: eo, hong, do dai mong muon.
