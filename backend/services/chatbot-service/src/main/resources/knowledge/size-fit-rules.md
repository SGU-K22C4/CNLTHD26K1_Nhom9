# Size And Fit Rules

## General Zara fit guidance

- many Zara-like items run slightly smaller than common Vietnam expectations
- if the customer is between two sizes, prefer sizing up for shirts, blazers, slim trousers, and layered outerwear
- do not sound absolute unless the measurements are strong enough

Preferred explanation style:

`Ban dang nam trong khoang size S-M. Neu muon mac thoai mai hon hoac vai/nguc day hon thi M se an toan hon.`

## Tops

### Basic tees

- usually true to size
- cotton stretch gives more tolerance

### Shirts and blouses

- size up if shoulders are broad
- size up if chest is above 88 cm

### Knitwear

- usually true to size because of stretch

### Crop tops

- true to size
- can size down if the customer wants a closer fit and body measurements are small

## Bottoms

### Trousers

- size up if thighs are fuller
- size up if hips are above 92 cm

### Skinny jeans

- often size up by 1
- sometimes size up by 2 if hips and thighs are both fuller

### Straight or wide jeans

- usually follow waist measurement first

### Shorts

- true to size by waist

## Dresses and skirts

- prioritize waist and hip over weight
- A-line and flare shapes are usually safer
- wrap dresses should consider both chest and waist
- midi and maxi lengths must consider height

## Blazers and outerwear

- shoulder fit is the first priority
- fitted blazers may need one size up if the customer has broad shoulders or fuller chest
- oversized blazers can stay true to size, or size down if the customer still wants an oversized look but less volume
- trench coats usually size up for layering

## Height notes

- under 158 cm wearing long pants may need hemming
- above 170 cm should prefer longer inseam or wider leg silhouettes
- midi and maxi skirts should consider total height before confirming

## High-confidence reply patterns

- `Zara thuong nho hon size Viet mot chut, nen neu ban phan van giua hai size thi minh nghi size lon hon se thoai mai hon.`
- `Voi quan thi phan dui va mong quan trong hon, eo co the chinh lai nhung dui chat thi rat kho mac dep.`
- `Voi blazer, phan vai la diem quan trong nhat. Neu vai vua dep thi cac phan con lai de xu ly hon.`
